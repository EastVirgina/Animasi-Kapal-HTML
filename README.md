🚢 Interactive Boat Animation
Sebuah eksperimen visual menggunakan HTML5 Canvas dan JavaScript untuk menciptakan animasi kapal yang bergerak dinamis dengan efek lingkungan.

🚀 Fitur Utama
- Canvas Rendering: Menggunakan API Canvas untuk performa animasi yang ringan dan mulus.
- Dynamic Movement: Simulasi pergerakan kapal yang responsif.
- Clean Code: Struktur kode JavaScript yang modular dan mudah dikembangkan.

🛠️ Teknologi yang Digunakan
- HTML5: Struktur utama dan elemen Canvas.
- CSS3: Styling dasar untuk layout yang responsif.
- JavaScript (Vanilla): Logika utama animasi, kalkulasi koordinat, dan loop render.

📁 Cara Menjalankan
1. Clone repositori ini: git clone https://eastvirgina.github.io/Animasi-Kapal-HTML/
2. Buka file `boat.html` di browser favorit Anda.
3. Nikmati animasinya!

📝 Dokumentasi Teknis
Proyek ini dikembangkan dengan fokus pada manipulasi DOM dan pemahaman sistem koordinat pada elemen Canvas untuk menghasilkan pergerakan objek yang halus.
